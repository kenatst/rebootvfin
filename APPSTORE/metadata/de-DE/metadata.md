## Description
Jede Benachrichtigung, jeder Feed, jede Unterbrechung reißt deine Aufmerksamkeit auseinander. REBOOT trainiert sie zurück.

**SO FUNKTIONIERT ES**
Jeden Tag schreibt REBOOT eine kurze Übung vor: bei einer Sache bleiben, nach einer Ablenkung zurückkehren, Behaltenes abrufen. Deine ehrlichen Rückmeldungen werden zu Evidenz. Das Programm passt sich dem an, was dir wirklich hilft.

**EIN PROGRAMM, KEINE TRICKLISTE**
- 90 Tage in sechs Phasen: Kalibrieren, Input kontrollieren, Stabilität, Tiefe, Flow-Bedingungen, Selbstständigkeit.
- Ein Tag verpasst? Nichts geht verloren. Keine Serien, kein schlechtes Gewissen.
- Freies Training bleibt jederzeit verfügbar.

**ES LERNT DICH KENNEN**
- Sitzungen zeigen dein echtes Fokusfenster – nicht das, was du über dich glaubst.
- Experimente prüfen, ob eine Gewohnheit dir wirklich nützt – mit klarer Antwort: behalten oder streichen.
- Umgebungs-Werkzeuge (optionaler Bildschirmzeit-Schutz) reduzieren digitale Reibung beim Üben.

**DAS ZIEL**
Tag 90 endet mit deinem Aufmerksamkeits-Handbuch: was deine Aufmerksamkeit bricht, wie du zurückkommst, welche Bedingungen deine tiefste Arbeit tragen – aufgebaut auf deiner eigenen Evidenz, nicht auf Durchschnittswerten. Danach hält der Eigene Modus es nützlich, ohne endloses Programm.

**DATENSCHUTZ VON GRUNDS AUF**
Alles bleibt auf deinem Gerät. Kein Konto, keine Cloud, keine Analyse, kein Tracking.

**BITTE BEACHTEN**
REBOOT trainiert Aufmerksamkeitsverhalten. Es ist kein medizinisches Produkt und diagnostiziert oder behandelt keine Erkrankung.
